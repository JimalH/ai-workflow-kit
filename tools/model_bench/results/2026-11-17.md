# model_bench results, 2026-11-17

One run per configuration. Hidden check: 80 cases. Quality and overall are the two blind
reviewers' scores out of 10 (gpt-6.1-sol / Claude Fable 5.2); overall also weighs time,
tokens and cost. Tokens are summed over every request of the run. Claude cost is reported
by the CLI; the others are list price x tokens (DeepSeek off-peak).

Conditions: Windows 11, Python 3.13 from PATH (the shared conda env was added to the kit
after these runs), every tool with the global rules file loaded (AI rules v1.7).

## Findings (each bug reproduced by hand)

- `deepseek-v4-pro` at `high` read `N/S` as the single value N; its own tests and its final
  message did not notice. At `low` it raises `OverflowError` near year 9999. Last in both rounds.
- `deepseek-flash` at `low` matched the Claude and Codex models on quality for about $0.02;
  at `high` it was slower, dearer and gained an overflow bug.
- Raising Codex from `low` to `medium` raised terra's quality score (6.5 to 8 on average)
  for about 45 s more.
- Claude Fable 5.2 at `medium` rejected steps longer than four digits (`*/10000`).
- Standing rules: only Claude Fable 5.2 and gpt-6.1-sol wrote the changelog entry the global
  rules asked for (both rounds).
- Reviewer bias: the gpt-6.1-sol reviewer ranked the two Codex submissions first in both
  rounds and scored gpt-6.1-sol's own work 9 and 10 where the other reviewer gave 7.

## Limits

One task, one run per configuration; the same model moved by one to two points between
rounds. Every model but one passed the whole hidden check, so the task does not separate
models on correctness.
